## Upload from GitHub website

1. Create a new repository.
2. Choose **Public** if you want everyone to see it, or **Private** if you are not ready yet.
3. Open **Add file → Upload files**.
4. Upload the files from this folder directly. Do not upload the ZIP as the project contents.
5. Use a commit message such as:

```text
Initial release
```

6. Commit the files.

## Important before making it Public

Search your files one last time for real tokens, IDs or secrets. This package contains placeholders only, but always verify the files you are actually uploading.
