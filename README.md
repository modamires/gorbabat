# گوربابات 😼

https://t.me/gorbabat_bot

گوربابات یک ربات فارسی تلگرام با شخصیت خودش است؛ برای وقت‌هایی که تنها چیزی که لازم داری یک عکس گربه است.

با گفتن یا نوشتن **«پیش پیش»** عکس گربه می‌فرستد، می‌تواند روزانه خودش سراغت بیاید و در کنارش چند قابلیت جدی‌تر و چند اتفاق نه‌چندان قابل پیش‌بینی هم دارد.

## امکانات

* 🐱 ارسال عکس تصادفی گربه با «پیش پیش»
* 🎙️ تشخیص «پیش پیش» از روی ویس
* 🔔 میو روزانه با امکان روشن و خاموش کردن
* 🔥 استریک روزانه و لقب‌های مختلف
* 📊 آمار شخصی کاربران
* 🏆 Achievementها و اتفاق‌های مخفی
* 🎲 Random Eventهای نادر
* 🥷 پیام ناشناس و امکان ادامه‌ی گفتگو با مدیر
* 📣 ارسال پیام همگانی توسط مدیر
* 👥 آمار، لیست کاربران و آخرین فعالیت
* 🩺 بررسی وضعیت ربات با ابزارهای مدیریتی

بعضی رفتارهای گوربابات عمداً در README توضیح داده نشده‌اند. باید پیدایشان کنی.

## تکنولوژی

* JavaScript
* Telegram Bot API
* Cloudflare Workers
* Cloudflare KV
* Cloudflare Workers AI
* Cron Triggers
* Cataas

## تنظیمات

Worker به این متغیرها و Bindingها نیاز دارد:

```text
BOT_TOKEN
WEBHOOK_SECRET
ADMIN_CHAT_ID
BOT_KV
AI
```

`BOT_KV` یک KV Namespace و `AI` یک Workers AI Binding است.
