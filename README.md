# 😼 گوربابات

گوربابات یک ربات تلگرام فارسی، گربه‌ای، بدقلق و کمی بی‌اعصاب است که روی **Cloudflare Workers** اجرا می‌شود.

ربات علاوه بر ارسال عکس گربه با «پیش پیش»، قابلیت چت با Workers AI، تشخیص «پیش پیش» در ویس، استریک، آمار، میو روزانه، پیام ناشناس، دستاوردها و Easter Eggهای مخفی را هم دارد.

> نسخه فعلی: **v2.1.2**

---

## ✨ قابلیت‌ها

### 🐱 پیش پیش
با فرستادن:

```text
پیش پیش
```

ربات یک عکس گربه تصادفی می‌فرستد.

«پیش پیش» در متن‌های طولانی‌تر هم تشخیص داده می‌شود.

---

### 🎙️ پیش پیش با ویس

ویس تلگرام با **Whisper Large V3 Turbo** در Cloudflare Workers AI پردازش می‌شود.

اگر داخل ویس «پیش پیش» تشخیص داده شود، ربات عکس گربه می‌فرستد.

مدل:

```text
@cf/openai/whisper-large-v3-turbo
```

---

### 💬 چت با گوربابات

هر پیام خصوصی عادی که دستور، «پیش پیش» یا Easter Egg نباشد وارد مسیر چت می‌شود.

گوربابات اول به زبان خودش جواب می‌دهد:

```text
میو میو میو میو
```

و زیر پیام یک دکمه نمایش داده می‌شود:

```text
ترجمه به زبون آدمیزاد
```

با زدن دکمه:

1. پیام موقت «دارم ترجمه می‌کنم...» نمایش داده می‌شود.
2. حالت `typing` تلگرام فعال می‌شود.
3. پاسخ هوش مصنوعی تولید می‌شود.
4. همان پیام موقت با پاسخ نهایی جایگزین می‌شود.

مدل اصلی:

```text
@cf/qwen/qwen3-30b-a3b-fp8
```

مدل fallback:

```text
@cf/zai-org/glm-4.7-flash
```

اگر Qwen پاسخ نهایی مناسبی برنگرداند، ربات خودکار GLM را امتحان می‌کند.

## 😾 شخصیت چت‌بات

گوربابات یک گربه خیابانی فارسی‌زبان است:

- لجباز و حاضر‌جواب
- کم‌حوصله و کم‌حرف
- گستاخ و کمی بددهن
- شرور و اهل کل‌کل
- کمی هیز و زن‌باره، در حد شوخی و متلک کوتاه
- در عین حال موظف به پاسخ مرتبط و منطقی

شخصیت روی **لحن** اثر می‌گذارد، نه روی صحت جواب.

گوربابات همچنین درباره قابلیت‌های واقعی و رازهای خودش اطلاعات دارد و می‌داند سازنده‌اش «حاج امیر آقای گل» است.

لقب‌ها با افزایش استریک تغییر می‌کنند و بعضی رکوردها Achievement مخفی دارند.

## 🔔 میو روزانه

کاربر می‌تواند ارسال خودکار گربه را روشن یا خاموش کند.

دکمه‌های اصلی:

```text
🔔 فعال کردن میو روزانه
🔕 قطع میو روزانه
```

ارسال خودکار از طریق **Cloudflare Cron Trigger** انجام می‌شود.

برای روزی دو بار ارسال، دو Cron Trigger در زمان‌های دلخواه بساز.

## 🥷 پیام ناشناس

کاربر می‌تواند متن، عکس، ویس، ویدیو، فایل یا استیکر را بدون نمایش هویت برای مدیر ربات بفرستد.

گفت‌وگو قابلیت ادامه دادن با Reply دارد و مدیر نیز می‌تواند روی پیام ناشناس Reply کند.

دستور مدیر برای بستن مکالمه:

```text
/anonclose
```

### Broadcast

ارسال برای همه:

```text
/broadcast متن پیام
```

فقط کاربران فعال ۷ روز اخیر:

```text
/broadcast active7 متن پیام
```

فقط کاربران دارای میو روزانه:

```text
/broadcast daily متن پیام
```

برای عکس، ویس، ویدیو یا فایل نیز می‌توان روی پیام Reply کرد و `/broadcast` را فرستاد.

ارسال همگانی قبل از اجرا نیاز به تأیید Inline Button دارد.

# ⚡ بهینه‌سازی Cloudflare KV

نسخه‌های قدیمی تقریباً با هر پیام خصوصی یک KV write انجام می‌دادند؛ این موضوع می‌توانست سهمیه رایگان Cloudflare KV را سریع مصرف کند.

در v2.1.2:

- پروفایل کاربر فقط هنگام ایجاد، تغییر مشخصات یا حداکثر تقریباً روزی یک‌بار نوشته می‌شود.
- اجرای دوباره `/start` بی‌دلیل write جدید ایجاد نمی‌کند.
- Burst مربوط به «پیش پیش» در حافظه Worker نگه داشته می‌شود.
- مسیر «پیش» نصفه در حافظه Worker نگه داشته می‌شود.
- آمار گربه‌ها در حافظه cache می‌شود و حدود هر ۱۵ دقیقه flush می‌شود.
- refresh پروفایل تلگرام حدود ماهی یک‌بار انجام می‌شود.
- `/health` برای تست KV فقط read انجام می‌دهد.
- خطاهای KV با wrapperهای امن مدیریت می‌شوند تا خرابی KV تا جای ممکن کل ربات را نخواباند.
- کاربران بلاک‌کننده با یک tombstone غیرفعال می‌شوند تا چند delete پشت‌سرهم مصرف نشود.

> حافظه Worker موقتی است و ممکن است با restart یا جابه‌جایی isolate پاک شود؛ داده‌های مهم همچنان در KV نگهداری می‌شوند.

# ☁️ راه‌اندازی روی Cloudflare Workers

## 1. ساخت Telegram Bot

در BotFather یک Bot بساز و Token را دریافت کن.

به Token نیاز داری:

```text
BOT_TOKEN
```

---

## 2. ساخت Worker

یک Cloudflare Worker بساز و محتوای `worker.js` را Deploy کن.

---

## 3. KV Namespace

یک KV Namespace بساز و Binding آن را دقیقاً با این نام به Worker متصل کن:

```text
BOT_KV
```

---

## 4. Workers AI Binding

Workers AI را با Binding زیر اضافه کن:

```text
AI
```

این Binding برای چت‌بات و تشخیص ویس استفاده می‌شود.

---

## 5. Variables / Secrets

Worker از این متغیرها استفاده می‌کند:

| نام | کاربرد |
|---|---|
| `BOT_TOKEN` | توکن ربات تلگرام |
| `WEBHOOK_SECRET` | Secret برای اعتبارسنجی Webhook |
| `ADMIN_CHAT_ID` | Chat ID عددی مدیر |
| `BOT_KV` | KV Binding |
| `AI` | Workers AI Binding |

`BOT_TOKEN` و `WEBHOOK_SECRET` را بهتر است به صورت **Secret** ذخیره کنی.

---

## 6. تنظیم Webhook تلگرام

بعد از Deploy، URL Worker را بردار:

```text
https://YOUR-WORKER.YOUR-SUBDOMAIN.workers.dev/
```

سپس Webhook را با همان `WEBHOOK_SECRET` تنظیم کن.

نمونه:

```bash
curl -X POST "https://api.telegram.org/bot<BOT_TOKEN>/setWebhook" \
  -d "url=https://YOUR-WORKER.YOUR-SUBDOMAIN.workers.dev/" \
  -d "secret_token=<WEBHOOK_SECRET>"
```

Worker فقط درخواست‌هایی را قبول می‌کند که Header مربوط به Secret Token صحیح داشته باشند.

---

## 7. Cron Trigger

برای میو روزانه در Cloudflare Worker بخش **Triggers → Cron Triggers** را تنظیم کن.

اگر می‌خواهی روزی دو بار ارسال شود، دو زمان جدا تعریف کن.

# 🔐 نکات امنیتی

- `BOT_TOKEN` را داخل GitHub commit نکن.
- `WEBHOOK_SECRET` را داخل سورس قرار نده.
- Secrets را در Cloudflare Dashboard نگه دار.
- `ADMIN_CHAT_ID` باید Chat ID عددی حساب مدیر باشد.
- اگر ریپو Public است، قبل از Push مطمئن شو Token یا Secret داخل هیچ فایل commit نشده باشد.
