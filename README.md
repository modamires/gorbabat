# 😼 Gorbabat

**گوربابات** یک ربات تلگرامی فارسی، بامزه، بدقلق و مجهز به «هوش گربه‌ای» است که روی Cloudflare Workers اجرا می‌شود.

🐱 ارسال عکس تصادفی گربه با «پیش پیش»  
🎙️ تشخیص «پیش پیش» داخل ویس فارسی  
🧠 چت با هوش مصنوعی با شخصیت اختصاصی گوربابات  
🐦 دانلود متن و مدیای پست‌های X / Twitter  
🥷 پیام ناشناس و گفت‌وگوی دوطرفه با مدیر  
🔥 Streak، لقب، Achievement و اتفاق‌های شانسی  
🥚 ده‌ها Easter Egg و قابلیت مخفی  
🔔 ارسال خودکار گربه با Cron  
🗞️ آرشیو Broadcastها با `its modam💫`  
📣 سیستم Broadcast پین‌شونده برای کاربران  
📊 آمار کاربران و فعالیت ربات  
🩺 Health Monitor با گزارش KV، Telegram، API latency، RAM، CPU و Cloudflare Metrics  

## Stack

- Cloudflare Workers
- Cloudflare Workers KV
- Cloudflare Workers AI
- Telegram Bot API
- Qwen 3
- GLM
- Whisper Large V3 Turbo
- FxTwitter
- Cloudflare GraphQL Analytics
