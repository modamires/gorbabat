# Gorbabat v2.6.1 — mEwCONOMY UI polish

- Mini App UI is now English.
- The only Persian sentence intentionally kept under the `mEwCONOMY` title is:
  `به امید عبور از این روزهای سخت 🤍`
- Card titles are now concise market symbols:
  USD, EUR, GBP, AED, TRY, CAD, GOLD 24K, GOLD 18K, MESGHAL, XAU, EMAMI, BAHAR, HALF, QUARTER, GRAM.
- Price digits remain English (`en-US`).
- Visible units are English: `Toman` / `USD`.
- Source selector, tabs, status pills, loading/errors and footer are English.
- Clicking/tapping a price card now creates a cat-paw animation only inside that card:
  1. soft appear
  2. smooth upward float by a few pixels
  3. gentle fade-out
- Repeated taps restart the paw animation cleanly on that card only.
