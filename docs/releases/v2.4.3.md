# Gorbabat v2.4.3 — Admin performance + User Monitor

Performance / reliability fixes:
- `/stats`, `/users`, `/starters`, `/userstats`, `/health`, `/helth`, `/cronstatus` برای ادمین دیگر داخل post-response `waitUntil()` اجرا نمی‌شوند؛ همان invocation منتظر تکمیلشان می‌ماند تا به سقف ۳۰ ثانیه‌ی waitUntil بعد از پاسخ وابسته نباشند.
- `/users` و `/starters` دیگر روی تک‌تک کاربران `getChat` تلگرام نمی‌زنند. فقط رکوردهای آلوده قدیمی با username بات repair می‌شوند.
- خواندن لیست کاربران از تقریباً 3 KV GET به‌ازای هر کاربر به 1 profile GET به‌ازای هر کاربر کاهش یافت؛ daily/starter از Setهای حاصل از KV.list خوانده می‌شوند.
- KV GET و KV.list در خطاهای موقتی تا 3 بار با backoff کوتاه retry می‌شوند؛ health بعد از تمام شدن retryها همچنان outage واقعی KV را گزارش می‌کند.
- درخواست‌های Telegram API timeout هشت‌ثانیه‌ای دارند تا یک fetch گیرکرده کل task را آویزان نکند.
- آخرین فعالیت داخل isolate نیز بدون KV write اضافه track می‌شود و در گزارش‌ها روی timestamp ذخیره‌شده overlay می‌شود.

New admin command:
- `/userstats`
- لیست تعاملی کاربران با Inline Keyboard، مرتب از آخرین فعالیت.
- pagination هشت‌تایی.
- با انتخاب هر کاربر پرونده شخصی شامل نام، username، ID، آخرین فعالیت ثبت‌شده، first seen، Starter، Daily، کل/امروز پیش‌پیش، streak، رکورد، لقب، دستاوردها، Legendary، Duck، Extra Cat، Sulk، Protest، Night/Half Pish و irritation نمایش داده می‌شود.
- دکمه «🔄 تازه‌سازی» و «⬅️ برگشت به کاربران» دارد.
