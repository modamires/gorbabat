# Gorbabat v2.5.4 — TGJU + blank Mini App button

## Mini App menu button
- Telegram Bot API requires a non-empty `text` for MenuButtonWebApp.
- The button label is now U+2063 INVISIBLE SEPARATOR, so visually nothing is written on the button.
- The button still opens `/economy`.
- Run `/setupminiapp` once after deploy so Telegram receives the new blank-looking label.

## MioEconomy
- BRSAPI and Navasan were fully removed.
- Source is now TGJU / شبکه اطلاع‌رسانی طلا، سکه و ارز.
- Worker tries TGJU `/tv/` first, then mirror/home fallbacks.
- Data is parsed from TGJU's live price display.
- TGJU domestic prices are denominated in rial; MioEconomy divides by 10 and displays toman.
- Supported when present: USD, EUR, GBP, AED, TRY, gold 24, gold 18, mesghal, ounce, Emami, Bahar, half coin, quarter coin.
- Individual market time from TGJU is shown on cards when available.
- Cache key was changed so stale BRSAPI data cannot survive deployment.
