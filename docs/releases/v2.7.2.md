# Gorbabat v2.7.2

## Jalali date in Finglish
The Mini App date is Persian/Jalali again, but rendered with Latin digits and
English/Finglish month names.

Example:
`14 Sahrivar 1405 · 15:30`

Implementation:
`Intl.DateTimeFormat("en-GB-u-ca-persian-nu-latn")`

`Shahrivar` is explicitly rendered as `Sahrivar` to match the requested style.

## Gold reference checks
The selectable named sources remain:
- TGJU
- Tasnim
- Smart average

Three additional GOLD 18K reference sources are used only when Smart average
is selected:
- Milli (`milli.gold`)
- MelliGold (`melligold.com`)
- TalaSea (`talasea.ir`)

Each reference tries the official website first and has the brand's official
public price feed as a resilience fallback for JS-only/redirect-heavy pages.

These extra sources do not appear in the source selector and do not provide
currency/energy quotes. They only corroborate GOLD 18K.

The existing robust consensus/outlier filtering still runs after all quotes are
collected, so a stale or wildly wrong reference cannot pull the gold average
away from the agreeing cluster.

## Paw animation
- Upward travel increased substantially (to about 46px).
- Every click creates a brand-new independent paw.
- Existing paws are never killed or restarted.
- Each paw removes only itself after its own animation.
- The paw originates near the click/tap position inside the clicked card.
