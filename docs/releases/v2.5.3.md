# Gorbabat v2.5.3 — Telegram Mini App Menu Button

- میوقتصاد همچنان هیچ دکمه‌ای به Reply Keyboard اصلی اضافه نمی‌کند.
- با Telegram Bot API `setChatMenuButton`، میوقتصاد به دکمه Menu کنار کادر تایپ چت خصوصی وصل شد.
- نوع دکمه `web_app` و مقصد آن `/economy` است.
- دستور ادمین `/setupminiapp` اضافه شد؛ یک بار بعد از Deploy اجرا شود تا Default Menu Button برای همه کاربران ثبت شود.
- `/setupminiapp` بعد از ثبت، با `getChatMenuButton` تنظیم را Verify می‌کند.
- روی `/start` هم به صورت best-effort تنظیم Default Menu Button دوباره اعمال می‌شود تا کانفیگ خودترمیم باشد.
- `/economy` به عنوان راه جایگزین باز کردن Mini App حفظ شده.
- منوی اصلی Reply Keyboard بدون دکمه میوقتصاد باقی مانده.
