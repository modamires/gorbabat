# Gorbabat v2.5.0

## 📈 میوقتصاد
- Telegram Mini App جدید با رابط موبایلی RTL و تم سازگار با Telegram.
- نمایش دلار، یورو، پوند، درهم، لیر، دلار کانادا، طلای ۱۸، آبشده، انس، سکه امامی، بهار، نیم، ربع و گرمی.
- دسته‌بندی ارز / طلا / سکه.
- درصد تغییر، جهت رشد/افت و زمان آخرین بروزرسانی.
- Refresh داخل Mini App.
- Backend rate proxy داخل Worker؛ API Key سمت کاربر لو نمی‌رود.
- Cache پیش‌فرض 120 ثانیه برای جلوگیری از مصرف بی‌رویه API.
- Provider اصلی Arzhaam و fallback قابل تنظیم Navasan.

## 📧 میومیل
- برای هر کاربر mailbox اختصاصی روی @modam.com.
- username تلگرام به عنوان local-part در اولویت.
- fallback امن برای کاربران بدون username یا collision.
- Email Worker handler داخل همان Worker.
- Catch-all Email Routing می‌تواند ایمیل را به Worker بدهد.
- ایمیل ورودی به چت همان کاربر در Telegram تحویل می‌شود: From, To, Subject, Body.
- MIME text/plain و HTML fallback، Base64 و quoted-printable به شکل سبک پشتیبانی می‌شود.
- نام attachmentها اعلام می‌شود.
- plus-addressing مثل `username+shop@modam.com` هم به mailbox اصلی route می‌شود.
- دستور ادمین `/syncmailboxes` برای ساخت mailbox کاربران فعلی.
- کاربران جدید در `/start` mailbox می‌گیرند.
- دکمه `📧 میومیل` آدرس شخصی کاربر را نشان می‌دهد.
