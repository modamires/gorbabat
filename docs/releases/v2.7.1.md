# Gorbabat v2.7.1

## Sources
Only these two MioEconomy sources remain:
- TGJU
- Tasnim

Default source: TGJU
Optional source: Tasnim
Smart average: still selectable

ESTJT, Mesghal and AlanChand were removed from the source registry, selector and fetch code.

## Tasnim is no longer gold-only
Tasnim is fetched through three independent current channels:
1. latest market/gold/coin report
2. latest currency report
3. latest oil/energy report

The Tasnim parser now supports:
- GOLD 18K
- MESGHAL
- XAU
- EMAMI
- BAHAR
- HALF
- QUARTER
- GRAM
- USD
- EUR
- AED
- GBP / TRY / CAD when those values are actually present in the fresh Tasnim report
- BRENT

The three Tasnim channels fail independently, so a missing energy article will not discard fresh gold/currency data.

## Correctness note for FX
Tasnim's recent currency reports quote official Iran Exchange Center selling rates.
TGJU cards are free-market rates.

They are both valid, but they are different markets.
Therefore:
- Tasnim official FX is visible when Tasnim is selected.
- Tasnim official FX is NOT blended with TGJU free-market FX in Smart average.
- Comparable gold/coin/global-energy values can still be averaged.

## Language / date
The entire visible Mini App is English except exactly:
`به امید عبور از این روزهای سخت 🤍`

Dates use:
`en-GB-u-ca-gregory-nu-latn`

This forces Gregorian dates and Latin digits, so Persian month names cannot appear.
