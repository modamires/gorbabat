# Gorbabat v2.5.1 — MioEconomy only

- میومیل کاملاً از UI، command route، Email Worker handler و کدهای mailbox حذف شد.
- میوقتصاد باقی ماند و Zero-Config شد.
- منبع اصلی نرخ‌ها BRSAPI رایگان است و هیچ API Key برای اجرای اولیه لازم ندارد.
- دو endpoint عمومی BRSAPI به ترتیب v2 و v1 امتحان می‌شوند.
- parser انعطاف‌پذیر برای چند ساختار JSON و نام‌گذاری مختلف اضافه شد.
- اگر `NAVASAN_API_KEY` از قبل تنظیم باشد، فقط به‌عنوان fallback استفاده می‌شود.
- مینی‌اپ همچنان روی `/economy` و API داخلی روی `/api/economy` اجرا می‌شود.
- Cache پیش‌فرض 120 ثانیه است تا منبع رایگان بی‌جهت تحت فشار قرار نگیرد.
- واحد هر نرخ داخل خود کارت نمایش داده می‌شود.
- قابلیت‌های v2.4.3 و Achievement/Voice/Twitter/User Monitor دست‌نخورده ماندند.
