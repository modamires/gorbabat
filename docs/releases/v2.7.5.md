# Gorbabat v2.7.5

## Sources
Tasnim was completely removed from MioEconomy:
- source registry
- source selector
- fetch code
- parser code
- provider labels
- health/source copy

Selectable sources are now:
- TGJU
- Milli
- MelliGold
- TalaSea
- Smart average

Default remains TGJU.

## Tether / USDT
Added `USDT` to the market cards.

TGJU's Tether profile reports:
- global Tether rate in USD (~1)
- a separate local `rial price`

MioEconomy intentionally reads the `rial price`, then divides by 10 to display
Toman.

Example fixture:
`2,208,070 IRR -> 220,807 Toman`

This avoids the critical mistake of reading the global `1.00 USD` field as the
Iranian Tether price.

## Card order
All-source rendering is now explicitly sorted in this order:

1. USD
2. USDT

Then:
- GOLD 24K
- GOLD 18K
- MESGHAL
- XAU
- EMAMI
- BAHAR
- HALF
- QUARTER
- GRAM

Then:
- IQD
- EUR
- GBP
- AED
- TRY

The frontend enforces this order even if a source returns assets in a different
sequence.
