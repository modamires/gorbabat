# Gorbabat v2.6.0 — MioEconomy multi-source

## Fix: TGJU gold prices
The old implementation preferred TGJU `/tv/`. That page can expose a stale snapshot.
v2.6.0 completely removes `/tv/` and reads TGJU's current Gold, Coin, and Currency pages instead.

## Sources

- Mesghal
- AlanChand

## Default mode
`average` is the default source.
For each instrument, quotes from available sources are normalized to the same unit.

Outlier filtering does NOT use standard deviation.
It uses:
- median
- MAD (Median Absolute Deviation)
- relative safety band

A wildly high/low or stale quote is excluded before the arithmetic mean is calculated.
