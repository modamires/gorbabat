# Gorbabat v2.7.4

## Branding
`MeONEY؟! 🐾` changed to `MewONEY! 🐾`.

## TGJU currency bug
The currency issue was on our side.

The old TGJU code still had two failure modes:
1. it used an aggregate currency page that could lag behind live profile pages;
2. it scanned full TGJU pages for every asset, while TGJU sidebars contain
   labels for many other currencies. That could bind the current page's value
   to the wrong currency.

Fix:
- USD/EUR/GBP/AED/TRY/CAD/IQD now use dedicated TGJU live profile URLs.
- Every fetched page is restricted to its intended asset ID.
- Local TGJU values are explicitly treated as IRR and divided by 10 into Toman.
- New cache namespace prevents old currency payloads surviving deploy.

Regression fixture:
`2,272,050 IRR -> 227,205 Toman`.

## Tasnim currency bug
Tasnim's current reports use several sentence styles that the old parser missed,
including:
- `با ثبت رقم 160 هزار و 502 تومان`
- `نرخ فروش حواله یورو نیز ...`
- `با 130 تومان افزایش به 43 هزار و 703 تومان`
- `بهای فروش آن به ...`

The new parser:
- works sentence-by-sentence, so one currency cannot steal another currency's price;
- detects selling-rate context;
- ignores small daily-change amounts by selecting the actual larger selling quote;
- supports current USD/EUR/AED wording and recent alternative wording.

The daily Tasnim market article is now also parsed for currency quotes as a
fallback route, in addition to the dedicated currency service.

Tasnim official Exchange Center FX is still not mixed with TGJU free-market FX
inside Smart average.
