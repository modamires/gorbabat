# Gorbabat v2.6.2 — IQD + Brent

Added two MioEconomy instruments:

- `IQD` — Iraqi Dinar, displayed as **Toman per 1 IQD**
- `BRENT` — global Brent crude oil, displayed as **USD/bbl**

## IQD sources
- TGJU explicit `price_iqd` profile
- AlanChand `100 Iraqi Dinar`
- Mesghal is parsed opportunistically if an IQD row is present

Normalization:
- TGJU publishes IQD in IRR per 1 IQD -> divide by 10 to Toman.
- AlanChand publishes 100 IQD in IRR -> divide by 1000 to get Toman per 1 IQD.

This prevents the common x100 unit mistake.

## Brent
- TGJU `/energy` is used.
- Card title: `BRENT`
- Category: `Energy`
- Unit: `USD/bbl`

## UI
- New `Energy` filter tab.
- Existing English UI, English digits, blank Telegram Mini App button and paw animation are preserved.
