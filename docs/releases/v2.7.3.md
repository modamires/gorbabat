# Gorbabat v2.7.3

## Branding
`mEwCONOMY` was renamed to:

`MeONEY؟! 🐾`

The new branding is used in the page title and visible Mini App header.

## Jalali / Finglish date
The previous manual typo override:
`Shahrivar -> Sahrivar`
was removed.

Persian/Jalali date formatting remains:
`en-GB-u-ca-persian-nu-latn`

So September dates now correctly render like:
`14 Shahrivar 1405 · 15:30`

## Selectable sources
The source selector now contains:
- TGJU
- Tasnim
- Milli
- MelliGold
- TalaSea
- Smart average

Default remains TGJU.

Milli / MelliGold / TalaSea are GOLD 18K-only sources. Selecting one of them
shows the price feed available from that source.

Smart average still uses them as GOLD 18K corroboration sources with the
existing robust outlier filtering.

## Preserved behavior
- Persian subtitle remains the only Persian sentence.
- Subtitle remains RTL.
- Multi-paw animation remains independent per click.
- TGJU/Tasnim broader-market logic remains unchanged.
