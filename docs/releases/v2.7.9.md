# Gorbabat v2.7.9

## Three-dot history button
Every price card now has a top-right `⋯` button.

Pressing it opens a price-history bottom sheet for that exact card and source.

Supported for every card returned by:
- TGJU
- Milli
- MelliGold
- TalaSea
- Smart average

## Universal history backend
Because the external sources do not all expose compatible historical APIs,
mewMONEY! now builds its own source-agnostic history from verified price reads.

New endpoint:
`GET /api/economy/history?source=<source>&asset=<asset>`

Storage behavior:
- BOT_KV
- one compact snapshot per source every 15 minutes
- each snapshot stores all cards returned by that source
- 7-day retention
- capped at roughly 680 snapshots per source
- one KV write maximum per source per 15-minute bucket

## Chart UI
- Native SVG line chart; no external chart library.
- `24H` and `7D` range controls.
- Current raw source price above the chart.
- Existing Jalali/Finglish formatter used for chart timestamps.
- Observation count and selected-window price change below the chart.
- If fewer than two observations exist, the sheet explains that history is still building.

The current raw card price is merged as the newest point so the chart can show
the latest value even before a background KV write becomes visible.

## Interaction isolation
Pressing `⋯` does not:
- spawn a paw
- increment the 10-tap counter
- trigger the 10,000-Toman visual discount

Normal card taps retain all previous behavior.

Charts always use the raw source/API price, not the easter-egg discounted display value.
