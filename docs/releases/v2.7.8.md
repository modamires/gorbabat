# Gorbabat v2.7.8

## Exact brand
The Mini App page brand is now exactly:

`mewMONEY!`

The Telegram Mini App menu button remains exactly `mewMONEY!`.

## 10-tap price easter egg
For every Toman-denominated card:

- tap 10 times -> displayed price drops by 10,000 Toman
- tap 20 times -> another 10,000 Toman drop
- tap 30 times -> another 10,000 Toman drop
- and so on

The backend/source price is never changed. This is only a client-side visual easter egg.

## Animated countdown
Each 10,000 Toman drop is animated for about 900ms.
The number visibly counts down from its current displayed value to the new value.

If the user taps very quickly and reaches multiple 10-tap milestones while an animation
is still running, the extra 10K drops are queued and animated one after another.

The displayed price is clamped at zero and never becomes negative.

## Paw animation
The independent multi-paw behavior is preserved:
- every tap creates a new paw
- existing paws are never killed
- upward movement remains about 46px
